## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key or other LLMs API Key you consider. The API call architecture will have to be adapted.
3. Run the app:
   `npm run dev`
